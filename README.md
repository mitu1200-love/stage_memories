# Stage Memories Maker

写真とBGMからステージ想い出のスライドショー・動画を作るブラウザアプリ(PWA対応)。
サーバーには何もアップロードされず、すべてブラウザ内で完結します。

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成する(例: `stage-memories-maker`)
2. このフォルダの中身(`index.html`, `manifest.json`, `sw.js`, `icons/`)を
   そのリポジトリのルートにアップロードする(ドラッグ&ドロップでOK)
3. リポジトリの **Settings → Pages** を開く
4. **Source** を `Deploy from a branch` にし、Branch を `main` / `/(root)` に設定して **Save**
5. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできるようになる

`https://` 経由で配信されるので、動画のMP4変換(ffmpeg.wasm)がローカルで
直接ファイルを開いたとき([`file://`)に出ていたエラーも解消されます。

## PWAとして「ホーム画面に追加」する

上記のURLをスマホ・PCのブラウザで開くと、多くのブラウザで
「ホーム画面に追加」「アプリをインストール」といった案内が出ます。
インストールすると、通常のアプリのように単独のウィンドウ/アイコンから起動できます。

## ファイル構成

```
index.html   … アプリ本体
manifest.json … PWAの設定(アイコン・アプリ名など)
sw.js         … オフラインでもアプリの外枠が開けるようにするservice worker
icons/        … アプリアイコン(192px / 512px / iOS用)
```

## 注意

- 動画のMP4書き出し機能は、初回にブラウザ内で変換エンジン(ffmpeg.wasm、数十MB)を
  読み込むため、通信環境が必要です。
- 写真・BGM・生成物はすべてその場でブラウザのメモリ上に保持されるだけで、
  どこにも送信・保存されません(ページを閉じると消えます)。
